### 🔭 Featured Projects

#### 🛡️ The Integrated Sentinel
> A solid-state CBRN early-warning system built for defense applications.
* **Core Tech:** G-BioFETs, Surface Acoustic Wave sensor arrays, and edge processing to analyze sensor fusion data in real-time.

#### 📧 AI-Driven Phishing Email Detection Using NLP
> A robust machine learning pipeline designed to catch language-based phishing attacks by filtering formatting noise and identifying malicious text patterns.
* **Rigorous Cleaning Pipeline:** Stripped HTML backgrounds, used Regex to drop hyperlinks, removed punctuation, and normalized text (lowercasing, removing stop words) to isolate clean data.
* **Algorithm Evaluation:** Built and tested four distinct models to find the highest accuracy: **Naive Bayes** (statistical probability), **Logistic Regression** (mathematical boundary mapping), **Random Forest** (ensemble of 100 decision trees), and a **Simple Neural Network** to uncover hidden linguistic complexities.

#### 📰 AI-Powered Fake News Detection
> A complete ML workflow to process text data and classify news articles as "Fake" or "Real".
* **Pipeline:** Automated data loading, text cleaning, feature extraction, model training, performance evaluation, and visualization.

#### 🫀 Organ Donation Application
> A centralized platform aiming to simplify organ donor registration, spread awareness, and connect patients transparently.
* **The Problem:** Slow administrative processes, severe lack of transparency, and organ shortages lead to thousands of preventable fatalities.
* **The Solution:** 
  * Designed a simple, user-friendly donor registration process.
  * Engineered a secure, centralized database for both donors and patients.
  * Created transparent matching algorithms to drastically reduce transplant waiting times.
