#### 🌐 [AI-Driven Phishing Email Detection Using NLP]
Phishing attacks are getting more commomn because they trick people using language rather than just breaking into PCs. this projects build the macine learning pipeline to automatically catch these phishing email.

METHODOLOGY In machine learning, bad data leads to bad results. Raw emails are full of formatting noise that messes with the models. To fix this, we set up a strict cleaning pipeline: • Removing HTML: We stripped out the background code so only the visible text was left. • Filtering URLs: We used Regex to drop hyperlinks since they don’t help the model learn language patterns. • Dropping numbers and punctuation: We only kept al- phabetical characters so the focus stayed entirely on the words themselves. • Normalization: Everything was converted to lowercase, extra spaces were removed, and we dropped common stop words (like ”the,” ”and,” ”is”) that don’t add any predictive value.

ALGORITHMS IMPLEMENTED To find the most accurate system, four distinct machine learning algorithms were built and tested: • Naive Bayes (Multinomial): A probabilistic classifier based on Bayes’ Theorem. It calculates the statistical probability that an email is phishing based on the in- dividual frequencies of the words it contains. It is highly regarded as a baseline standard for text classification. • Logistic Regression (Parametric): This model attempts to draw a strict, mathematical boundary line between real and fake articles. It learns fixed patterns based on word frequencies. • Random Forest (Ensemble): Instead of relying on one system, this model creates a ”forest” of multiple decision trees (a committee of 100 mini-models). They all vote on whether the news is fake, which makes the final decision highly reliable. • Simple Neural Network (Deep Learning): Inspired by the human brain, this model uses interconnected layers of artificial neurons to uncover hidden, highly complex text patterns that simpler models might miss.
